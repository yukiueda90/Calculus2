  \section{移流拡散方程式の解の非負値性保存} 
  ここでは空間 $1$ 次元の線形移流拡散方程式
  \begin{equation}
    u_t = (u_x-bu)_x \qquad (x\in[0, 1), t>0), \tag{1a}
  \end{equation}
  \begin{equation}
      u(0, t) = u(1, t),\quad u_x(0, t) = u_x(1, t) \qquad (t\ge0) \tag{1b}
  \end{equation} 
  の解の非負値性保存と陽的スキームによる再現についてまとめる, ただし初期条件は $u(x, 0) = a(x)$ とし, 初期値 $a(x)$ および方程式の係数 $b=b(x, t)$ は境界条件 (1b) を満たすように与えられているとする. 
  このとき, 次が成立する: 
  \begin{prop}[最大値原理]
    移流拡散方程式 $(1)$ の解は 
    \[
      a(x)\ge 0 \quad (x\in[0, 1)) \implies u(x, t)\ge 0 \quad (x\in[0, 1), t\gt0) 
    \] 
    を満たす. 
  \end{prop}

  \begin{proof}
    背理法: 初期値が $a(x)\ge 0 \ (x\in[0, 1))$ に対し, $u(x, t)< 0$ を満たす $x$, $t$ が存在すると仮定する. ...
  \end{proof}

  さて, 次に移流拡散方程式 $(1)$ を差分法で離散化する. 
  $N$ を正の整数として $h=1/N$ と $\tau>0$ に対し, 
  \[
    x_i = ih,\qquad t_n = n\tau 
  \] とおき, また $b_i^n = b(x_i, t_n)$ とする. このとき, $u(x_i, t_n)$ の近似値 $u_i^n$ を求める陽的スキームが, いつでも非負値性保存を再現するとは限らない. 
  例として, まずは $u_{xx}$ に中心 $2$ 階差分, $(bu)_x$ に中心差分を適用した

    \dfrac{u^{n+1}_i - u^n_i}{\tau} = \dfrac{u_{i-1}^n - 2u_i^n + u_{i+1}^n}{h^2} - \dfrac{b_{i+1}^nu_{i+1}^n - b_{i-1}^nu_{i-1}^n}{2h}
  \] を考えてみよう. ...
