はじめに

この資料では解析学の基礎として特に 積分 について解説する.

高校数学では『積分とは微分の逆に相当する原始関数を求める操作であり, 面積, 体積や曲線の長さを求めるための計算テクニックとして利用される』といった解説がされることが多い. 確かに, 関数で表される領域の面積や体積, 曲線の長さを計算も積分の重要な応用ではあるが, 大学数学ではより広範囲に積分のアイデアを利用することになる. 具体的には, 『積分とは累計量, 蓄積量を求める操作である』と理解することで, 物理や工学, データサイエンスといった様々な分野に応用されることになる. この資料では, 積分の基本的な考え方と計算方法を学び, 様々な分野への応用につなげることを目標とする.

例えば, 時刻 $t$ における位置が $x(t)$ とすると, 速度 $v(t)$ は微分を用いて \[ v(t) = \dfrac{d}{dt}x(t) \] と表される. 逆に, 速度が $v(t)$ である場合, 時刻 $t=a$ から $t=b$ までの変位 (位置の変化量および方向) は積分を用いて \[ x(b) - x(a) = \int_a^b v(t)~dt \] と表すことができる. この積分を, 関数 $v(x)$ のグラフの面積と説明することも不可能ではないが, それよりも『微小時間における変位の累計量』という説明の方が自然である. このように, 面積や体積の計算以外にも, 積分のアイデアを利用できるようになることがこの資料の目的の一つである.

以降は, 大学数学における微分については既に学習済みであることを前提とする. 微分と積分は密接に関連するものであり, 特に応用の際には不可分な概念であるため, 以下で簡単に復習する. 不明な点があれば, 微分における対応する概念について改めて確認すること.

この資料では, 『積分とは何か?』という説明から, その応用に向けた様々な概念や計算テクニックを紹介していく. いくつかの内容は高校数学における積分の説明と重複する部分があることをご了承いただきたい. また, この資料の内容は予告なく変更, 修正, 削除される可能性があることもご了承いただきたい.

極限, 微分の復習

極限や微分は, 積分と密接に関連する概念であり, ここで最低限の復習をしておく.

『任意の実数よりも大きい』ことを表す記号 $\infty$ を 無限大 という.

無限大は実数では無い (多くの場合は数とすら認められない) ことに注意. 例えば, 関数 $f(x) = ax+b$ のように表記した場合, $x$ は実数 (や複素数) であることが想定されている. そのため, 厳密には関数 $f(x)$ に $x=\infty$ を代入する, といったことは認められない.

ある量を指定の値 (や無限大) に近づけた際, 関数や数列がある値 (や無限大) に限りなく近づくとき, その値を 極限 という.

例えば関数 $f(x)$ に対し, \[ \lim_{x\to0} f(x),\qquad \lim_{x\to\infty} f(x) \] のような表記は, 変数 $x$ を指定の値に近づけた際に (もしくは $x$ を限りなく大きくした際に) $f(x)$ がどの値に近づくかを表している. ここで『極限は, ある量を指定の値に どのように近づけるか に依らず関数や数列が同じ値に近づく場合にのみ存在する』ことに注意してほしい. 一変数関数の場合は, \[ \lim_{x\to +0}f(x),\qquad \lim_{x\searrow 0}f(x) \] のように, 『$x$ が正であり続けるようにしながら $0$ に近づける』といった操作を考えることがあるが, これは (片側極限などと呼ばれるものの) 一般には通常の極限とは異なるものである. ただし, \[ \lim_{x\searrow 0}f(x) = \lim_{x\nearrow 0}f(x) = a \] である場合, 実は『$x$ を $0$ に近づける際, どのように $0$ に近づけるかに依らず $a$ に近づく』ことが保証されるため \[ \lim_{x\to 0}f(x) = \lim_{x\searrow 0}f(x) = \lim_{x\nearrow 0}f(x) = a \] が成立する.

極限の表記は便利である反面, 数学的に厳密な解釈が難しい場合もあるため, より専門的にはいわゆる イプシロン・デルタ論法 が用いられるが, ここでは深入りしない.

  • 一変数関数 $f(x)$ に対し, 極限 \[ f'(a) = \lim_{h\to 0}\dfrac{f(a+h) - f(a)}{h} \] が存在するならば, これを関数 $f(x)$ の $x=a$ における 微分係数 という. また, このとき関数 $f$ は $x=a$ において 微分可能 であるという.
  • 関数 $f$ が区間 $I\subset \mathbb{R}$ の全ての点で微分可能ならば, $f$ は区間 $I$ において微分可能であるという. このとき, $x\in I$ を $f'(x)$ に対応させる関数 $f'$ を $f$ の 導関数 (derivative) という.
  • 多変数関数 $f(x_1, \dots, x_d)$ に対し, 極限 \[ \dfrac{\partial f}{\partial x_i}(a_1, \dots, a_d) = \lim_{h\to 0}\dfrac{f(a_1,\dots, a_i+h, \dots, a_d) - f(a_1, \dots, a_i, \dots, a_d)}{h} \] が存在するならば (直感的には $x_i$ のみ変数とみなし, それ以外は定数と思って微分可能ならば), これを関数 $f(\mathbf{x})$ の $\mathbf{x} = (a_1, \dots, a_d)$ における $x_i$ に関する 偏微分係数 という. また, このとき関数 $f$ は $\mathbf{x} = \mathbf{a} = (a_1, \dots, a_d)$ で $x_i$ に関して 偏微分可能 であるという.
  • 関数 $f$ が領域 $D\subset \mathbb{R}^d$ の全ての点で $x_i$ に関して偏微分可能ならば, $f$ は領域 $D$ において $x_i$ に関して偏微分可能であるという. このとき, $\mathbf{x}\in D$ を \[ \dfrac{\partial f}{\partial x_i}(\mathbf{x}) \] に対応させる関数を $f$ の $x_i$ に関する 偏導関数 (partial derivative) という.

多変数関数 $f(x_1, \dots, x_d)$ が領域 $D\subset\mathbb{R}^d$ において, 全ての $x_i$ に関して偏微分可能であるとする. このとき, ベクトル値関数 \[ \nabla f(x) = \begin{pmatrix} \dfrac{\partial f}{\partial x_1}(x) \cr \vdots \cr \dfrac{\partial f}{\partial x_d}(x) \end{pmatrix} \] を関数 $f$ の 勾配 (gradient) という. 関数 $f$ の勾配 $\nabla f$ を $\operatorname{grad} f$ と表記することもある.

多変数関数 $f(\mathbf{x})$ に対し, 与えられたベクトル $\mathbf{v}$ について極限 \[ \dfrac{\partial f}{\partial\mathbf{v}}(\mathbf{x}) = \lim_{h\to 0}\dfrac{f(\mathbf{x} + h\mathbf{v}) - f(\mathbf{x})}{h} \] が存在するならば, これを $f$ の $\mathbf{x}$ における $\mathbf{v}$ 方向の 方向微分 という. 方向微分を $\nabla_{\mathbf{v}}f(\mathbf{x})$ と表記することもある.

重要な性質として, $f$ が全微分可能 (つまり局所的に $1$ 次関数で近似できる) ならば, $f$ は全ての方向に方向微分可能であり (特に全ての $x_i$ について偏微分可能であり), また \[ \dfrac{\partial f}{\partial\mathbf{v}} = \nabla f\cdot \mathbf{v} \] が成立する. 実用上は, 関数 $f$ が $C^1$ 級であるならば (つまり全ての $x_i$ に対し偏微分可能であり, かつ全ての偏導関数が連続であるならば) 全微分可能であり, 従って上の式が成立することが重要である.
